### Origin & Tradition

**Evidence summary.** After searching every text and list on disk, no locus was found for any of the three tagged traditions. The tags appear to be inherited from an index, and one of them (SBJ) looks like a false match on a similar-sounding name, described below. This entry therefore records what was searched and what was not found. [USER: verify]

**Chinese — Shennong Bencao Jing (SBJ).** No locus was found. Yang 1998 (`Sources/SBJ_Shennong/text/Shennong_Yang_1998.txt`) contains no *Bidens*. The nearest printed string is the herb Niu Xi, "Niu Xi (Radix Achyrathis Bidentatae)" (line 1734, Superior Class), which is *Achyranthes bidentata*, a different plant in a different family. The word "bidentata" is the likely source of the spine's SBJ tag. Niu Xi's printed class does not transfer to this plant. [USER: verify]

**Ayurvedic — Sushruta (SS).** No locus was found. A search of the three Bhishagratna volumes (`Sources/SS_Sushruta/text/`) for *Bidens* returned nothing, and `Sources/SS_Sushruta/extract/names.csv` has no such row. `Sources/SS_Sushruta/views/gaps.csv` line 3863 lists this row as "ss_attested_no_evidence: not in chapters extracted so far". The ch.38 group lists give names without identifications, and ch.39 to 46 and the recipe chapters were not extracted, so absence from the extract is not proof of absence from the text.

**Nahua — Badianus (BM).** No locus was found. `_sources/badianus.csv` has no *Bidens* row. The only composite-family row that looks near is line 2, "Aca-capac-quilitl", *Aganippea dentata* (Gates 1939), and nothing read says that it is the same plant as *B. pilosa*. The plant name "tlanoquiloni" appears in an internal build script (`Volume_IX_Master_Register/expand_csv_2.py`, line 608, "BM wound medicine"), and the overview file quotes a remedy using "iztac tlanoquiloni" (`Sources/BM_Badianus/BM_Original_Latin_Nahuatl.md` lines 243 to 253, "white cleanser"). Neither source identifies it as *Bidens*, and the Badianus extract notes that the overview files are "judged unreliable" (`Sources/BM_Badianus/extract/README.md`). Neither is relied on.
